# Daily Desk brand files

| File | Use |
|---|---|
| `daily-desk-mark.svg` | Main symbol: blue tile, white + yellow D's. Header, login, splash. |
| `daily-desk-mark-reverse.svg` | White tile version for blue or dark backgrounds. |
| `daily-desk-letters.svg` | The two D's without the tile, for tight spaces on white. |
| `daily-desk-logo.svg` / `daily-desk-logo-reverse.svg` | Symbol + "Daily Desk" name (needs the Sora font installed to look right). |
| `favicon.svg`, `favicon.ico` | Browser tab icon (heavier version that stays sharp at 16–32 px). |
| `apple-touch-icon.png` (180), `icon-192.png`, `icon-512.png` | iPhone home screen and Android / PWA icons. |

Colours: Desk blue `#1F5BC6` · Sunrise yellow `#F5B800` · Ink `#15191F`.
Name: Sora SemiBold, both capital D's in blue (yellow on blue backgrounds).
